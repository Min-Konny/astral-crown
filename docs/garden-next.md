# 庭園の追加2面（ローカル候補）

素材導線の候補を保全したまま、既存6面の後に2面を追加。敵・画像・戦闘計算・育成方式は既存を使用し、新しい課金や召喚必須条件は設けない。

任意目標は従来通り素材120を一度だけ追加。初回・目標とも再受取なし。旧6面の値は変更せず、旧6面踏破・メダル63のセーブはそのまま7面を解放する。素材案内は新しい未踏破面／未達目標を自動的に反映する。

## 難度検証

- 新規セーブの初期3人で各勝利後に最大3巡、払える範囲だけレベルアップする固定方針を実行。召喚・疑似購入なしで8面までAUTO勝利。7面開始はノエル11/イリス9/ミラ8、8面開始は12/10/8。
- 7面のLv12初期編成ではAUTO・MANUALとも勝利。AUTOは範囲技軽減4人分、盾を温存するMANUALは5人分で任意目標達成。手動の選択が実際の計算に反映される。
- 8面は同一キャラでも隊列で結果が変わる。Lv18の盾・射手・回復の順では全員生存と時間目標を達成できる。
- 当初の8面倍率1.3は既存報酬だけでの育成経路を止めたため、新面のみ1.05へ調整。ステータス上昇ではなく回復役の配置と攻撃周期が課題。既存面は不変。
- 行動ごとの保存失敗・再試行・再読込、二重報酬防止、旧メダル保持、敗北時報酬なし、結果から次面／最終面の扱いを回帰検査。

全編成・全成長方針の攻略保証ではない。固定された戦闘条件での計算検証であり、人間の操作時間や実スマホの手触りを測ったものではない。調整可能なローカル候補として保存し、push・公開は行わない。

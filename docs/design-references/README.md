## レビュー時の前提

- 画像は完成イメージであり、現在のゲーム画面のスクリーンショットではありません。
- ソシャゲ風の買い切りインクリメンタルゲームです。現実のお金での課金はありません。
- 数値・回数・通貨・キャラクター名などは参考表現です。実際の仕様はゲームの要件と実装を優先してください。
- 特にホームと召喚の絵の密度、構図、装飾の統一感を比較してください。上部・下部の配置は各画像で案が異なります。

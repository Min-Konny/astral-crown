# 手動育成から戦闘へ（ローカル候補）

## 対象と仮説

既存の入手結果には枚数・強化可能表示と対象詳細への導線があり、詳細には手動昇格・能力比較がある。今回の不足は、育成後に「そのキャラを使えているか」「どこで試すか」が分かりにくい点とした。

育成詳細と昇格結果へ、編成中／未編成／編成不要の支援を区別する短い表示と、現在の能力・次の操作を追加。編成中または支援キャラは出撃前画面へ進み、既存の帰還導線で同じ育成詳細へ戻る。未編成なら主力一覧の対象編成ボタンへフォーカスし、勝手には編成しない。出撃自体も明示操作を維持する。

初めての育成から庭園戦まで、従来の「閉じる→闘技場→庭園選択→出撃」の4操作を「この編成で試す→出撃」の2操作へ短縮。訪問済み庭園があればそれを保持し、なければ次の解放済み庭園を提示する。結果や能力・報酬・セーブ形式は変更しない。C/UCの表示は一部ボーナスだけでなく現在の編成の攻撃合計を使用。

## 検証

- 117件の単体・回帰テスト。既存の旧セーブ移行、手動強化、保存失敗と報酬一回性を維持。実表示関数の非破壊性と3種類の所属表示を追加。
- 隔離プレビュー、合成の獲得済み10枚・未強化データでPC1280／390／320、通常／低モーションを確認するブラウザ回帰を追加。昇格失敗→再試行、連打、能力増加、出撃前のキャンセル帰還、戦闘→結果→再読込→育成、報酬重複なし、未編成の非自動編成、C支援の帰還を対象とする。
- ブラウザ回帰・スクリーンショットは公開対象外の `artifacts/trial-qa.mjs`、`trial-results.json`、`trial-before-*`、`trial-detail-after-*`、`trial-after-*`。同条件の詳細画面比較と昇格結果を分けて保存。
- ダイアログ終了イベントが編成ボタンのフォーカスを奪う競合を修正。QAで発生した意図しない編成は、検証側のbody誤選択によるものと特定し、buttonに限定して再確認。

## 限界

操作数と状態の整合は検証できるが、成長を楽しく感じるか、次戦へ進む意欲が増えるかは実プレイヤーの評価が必要。召喚の確率体験・長期継続率は本バッチでは測定しない。実スマホのタッチ・全GPUの全フレーム白化を保証しない。旧セーブ互換は既存モデル回帰で確認し、旧セーブ全種類の実画面再試験は行っていない。本セーブ、公開先、経済数値は変更しない。

## 新規セッション監査・追補

セーブを投入せず空の隔離ストレージから開始。再現用乱数seed42、初期資源のみで10連を実行した。獲得したカードは最大3枚で、全員が次の10枚昇格に届かない。先頭のCキャラ詳細は昇格不可・鍛錬には庭園クリアが必要。一方、初期主力は初期素材300と召喚素材80で直ちにレベル育成できる。この「カードはまだ強化できないが素材では強化できる」という違いが結果上部から分からなかった。

結果上部に、現在育成可能な編成中の1人とレベル・必要素材を示す任意の詳細リンクを追加。カード取得対象に限定しない。対象なし／素材不足／全員最大レベルなら出さない。クリックは詳細を開くだけで消費しない。チュートリアル強制や追加報酬はない。

実際の最終経路はホーム→10連→結果の「ノエル Lv.1→2 / 素材30」→詳細で手動レベルアップ→出撃準備→庭園1→勝利→再読込→ノエルの育成。ノエル攻撃48→51、HP710→767、素材380→350を確認。初期3人の編成を維持し、召喚で得たSSRは使用していない。昇格は未実行なので「初回でカード昇格まで体験できた」とは扱わない。Lv育成と戦闘のループは実際にアクセスできた。

PC1280／390／320×通常／低モーションの6条件で操作成功。途中の詳細キャンセルと再入場、表示だけでは消費なし、報酬後再読込でも素材不変、本localStorage未使用、横はみ出しなし。全118テスト・28ファイルビルド成功。素材不足・最大レベル・編成空の表示回帰を追加。

非公開証跡：`artifacts/first-session-qa.mjs`、`first-session-results.json`、`first-session-tests.txt`、`first-result-*`、`first-grown-*`。変更前比較は同一乱数・同一390pxで追加リンクのみ無効化した `first-before-result-390-false.png`。これは実ユーザーによる発見率の測定ではない。初見ユーザーが任意リンクを発見するか、カード昇格と素材育成を区別できるか、低レアの支援価値を理解できるかは実プレイヤー検証が必要。

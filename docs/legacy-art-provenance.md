# Final four legacy character assets

Selected existing ranger (蒼穹の斥候), smith (灯火の鍛冶師), guard (王都の衛兵), herbalist (森の薬草師), completing all13 dedicated chibi identities with the pending mage3 and published6. Previous shared atlas identities retained in hair/color/archetype: brown-haired archer becomes short-haired crossbow scout; blue-haired knight placeholders become hammer/apron smith and helmet/spear/buckler guard; pink-haired healer becomes braided herbalist with basket/bottle. All remain legacy characters and are not made selectable fighters.

Built-in image_gen.imagegen used for four originals, transparent_background=true. The smith, guard and herbalist each received one framing correction with the same tool, using only that immediately preceding/generated original as the edit reference (num_last_images_to_include=1). No outside references, franchise art, logo or existing character names sent. Existing project atlas was visually inspected, not supplied to generation. Model/version and generation IDs were not exposed. Exact returned PNG dataURL bytes decoded into workspace without further image editing; no guessed URLs. Original design request is not a non-infringement guarantee.

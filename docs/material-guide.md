# 育成から素材攻略への往復

未完だったのは、素材の入手先が説明文だけで、対象ステージと育てたいキャラを再選択する必要がある点。既存の6面・育成・報酬計算を再利用する小さな導線を追加した。

- 所持中のキャラ詳細に素材の所持数、次の育成費用と不足数を表示。レベル上限・鍛錬上限は候補費用から除く。鍛錬のレベル／巡回による解放条件は既存表示を参照する。
- 未踏破の次の庭園と、踏破済みだが任意目標を未達成の庭園を最大1件ずつ案内。解放されていない先の面と報酬受取済みの面は素材入手先にしない。
- 初回勝利の素材数と、任意目標の条件・素材120を区別し、いずれも1回限りと表示。全受取後は庭園を周回しても素材が得られないことを明記する。
- 案内は出撃前画面へ移動するだけで自動戦闘・自動育成は行わない。巡回画面と勝敗結果に元のキャラ詳細への戻り先を置く。既存の編成画面へは詳細を閉じて戻れる。
- キャラID・目的地・シーズンだけをタブ単位のsessionStorageに保持。保存データの形式や報酬処理は変更しない。途中の再読込後にも戻り先を復元し、不正値・未所持・別シーズンは無視する。タブ終了後の継続は対象外。

確認: 113件の単体／回帰テスト。隔離ブラウザPC1280/390/320、通常/低モーションで不足→案内→勝利→結果再読込→対象キャラ育成、キャンセル復帰、戦闘開始と育成の保存失敗、古いボタン連打、素材差引とfocusを検証。画像・音・報酬数値・白化抑制の配色は変更なし。実スマホや全描画フレームの保証ではない。

このバッチはローカル候補。公開・pushは行わない。

# 初回試作の検証記録

実施日：2026年10月21日

## 自動検証

Node.jsのテスト15件を実施。対象は購入・まとめ購入・10から10,000連までの資源整合性・SSR天井・低レアの全体効果・SSR5凸上限・編成制約・育成・戦闘報酬・二重反映防止・敗北・転生・セーブ検証・オフライン収入・配布の重複防止。

固定乱数による一周の統合検証では、初期資源から疑似購入・召喚・収入投資・育成を行い、50位に到達して転生し、引継ぎ後のデータを保存検証に通した。操作時間や演出時間を省いたシミュレーションであり、実プレイの所要時間を保証するものではない。

低レアの小さな加算を失わないよう、攻撃力は内部で小数を維持し、表示と実ダメージの段階で丸める修正を行った。

ローカルのアプリ内ブラウザで以下を確認。

- 初回のお詫び石受取
- クレジット風・キャリア風の疑似購入と石の受取
- 決済からガチャへの移動
- 10連と100連、召喚陣、SSR専用登場画面、レア別集計
- ガチャ結果の全体強化量
- 結果画面からの再召喚で石不足の案内が見え、資源が減らないこと
- キャラ育成による戦力の増加
- オートバトルのHP・行動表示、勝利、100位から95位への更新、報酬
- 再読み込みで通貨・キャラ・凸・受取済み状態が復元
- 演出短縮の設定と短縮時の即時結果表示
- 390×844のスマホ幅で召喚と購入を操作できること
- スマホの召喚画面で横方向にはみ出していないこと
- ブラウザの記録されたエラー・警告が0件

SSR演出の画像は `artifacts/ssr-reveal.jpg` に保存。

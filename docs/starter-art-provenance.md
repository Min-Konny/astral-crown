# Starter chibi artwork

Created with built-in image_gen.imagegen, transparent_background=true, one independent generation per character. The tool did not expose a model/version or generation ID. No external character art, logos or reference images were passed to generation. Existing project party.png and luna.png were visually reviewed to describe the matching style; neither was supplied as a generation reference.

The tool returned PNG data URLs. Their exact decoded bytes were saved under assets/ with normal workspace file tools. No guessed download URLs, external transfer service, image editing or alpha removal. These are original design requests, not a guarantee of non-infringement.

src/character-art.js provides one mapping for battle, summon and collection/training/result portraits. Existing party.png frames remain fallbacks for missing optional assets. Other heroes and Luna's full portrait are unchanged. These are chibi sprites, not full-height portrait unlocks.
